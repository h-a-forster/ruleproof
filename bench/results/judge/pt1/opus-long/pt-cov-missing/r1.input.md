I added the PO number field and the tests for it pass. However, plain `uv run pytest` does not work in this repo, and that was true before my change.

**The test problem:** `pyproject.toml` sets `addopts = "-q --cov=invoicing --cov-fail-under=90"`. Those `--cov` options need the pytest-cov plugin, which isn't installed, so pytest stops with `unrecognized arguments: --cov=invoicing --cov-fail-under=90` before running any tests. The handbook says the setting should be just `-q` and that we shouldn't add dependencies, so I left both the config and the dependencies alone. I ran the suite with the options overridden for that one run: `uv run pytest -o addopts=-q` gave **19 passed**, including the 3 new tests. Someone needs to choose a fix: either drop the `--cov` options from `addopts`, or add pytest-cov to the dev group after Security reviews it.
